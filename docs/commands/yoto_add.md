## yoto add

Add a track to a playlist

### Synopsis

Uploads and adds a new audio file to an existing playlist.

If a position is provided, the track is inserted there. Otherwise, it is appended to the end.

```
yoto add <playlist[/position]> <file> [flags]
```

### Examples

```
  # Append a track to a playlist
  yoto add "Bedtime Stories" ./new-chapter.mp3 --title "Chapter 1"

  # Insert a track at the beginning (position 1)
  yoto add "Bedtime/1" ./intro.mp3

  # Add with trimming
  yoto add "Bedtime" ./story.mp3 --trim-start 21 --trim-end 30
```

### Options

```
  -h, --help               help for add
      --icon string        Icon ID (hash or yoto:#...) to use for the track
  -t, --title string       Title for the new track (defaults to filename)
      --trim-end float     Trim N seconds from the end
      --trim-start float   Trim N seconds from the start
```
